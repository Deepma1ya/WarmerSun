WarmerSun v0.1.0 - DRM-free lighting grade for ETS2 / ATS.

Install: copy dxgi.dll, dinput8.dll and WarmerSun.ini into the game's bin\win_x64 folder.
Hotkeys: F10 toggle, F11 preset, F12 reload config.

What it does: warm filmic grade, white balance, pre/post contrast, saturation and vibrance, highlight/shadow recovery, adaptive exposure with night lift, CAS sharpening, four presets.

Verified with the included D3D11 harness on the reference pattern (preset D): warmth R/B 1.277 -> 1.413, contrast sigma 0.287 -> 0.315, highlight clipping 4.48% -> 4.08%.

No account, no license key, no network, no telemetry.

Note: this is a clean-room reimplementation of the reference mod's control surface and hook architecture. It grades the presented LDR frame; a shader-level HDR mode is the next phase.
